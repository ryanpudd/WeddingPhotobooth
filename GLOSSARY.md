# Wedding Photobooth

An unattended kiosk photobooth: a tablet and USB webcam rig that guests use to take, review, and keep photos.

## Language

**Inverted mount**:
The booth rig set up with the tablet and webcam both turned 180° as one unit, so the screen sits in reverse landscape and the camera sees the scene upside down.
_Avoid_: Upside-down mode, flipped, rotated mount

**Photo**:
A single image the booth captures and a guest keeps.
_Avoid_: Tile, picture, shot, capture

**Border**:
Decorative artwork, themed for the event (wedding, Halloween), that surrounds a photo.
_Avoid_: Frame, surround, overlay

**Window**:
The clear region of a border where the photo shows through.
_Avoid_: Hole, cut-out, inner frame

**Crop**:
The region of a photo, the same shape as the window, that is kept because it holds the interesting content.
_Avoid_: Cut, selection

**Interesting content**:
The people in a photo, plus any prop they are holding up.
_Avoid_: Subject, focus

**Framed photo**:
A new image made of a photo's crop shown in a border's window; the original photo is never changed.
_Avoid_: Bordered photo, composite
